## 🎬 Recording Tools

### Android
1. **Built-in Screen Recorder**
   - Swipe down notification panel
   - Tap "Screen Record"
   - Start recording
   - Perform actions
   - Stop from notification

2. **AZ Screen Recorder** (Free app)
   - Download from Play Store
   - High quality recordings
   - Easy editing

### iOS
1. **QuickTime Player** (Mac + iPhone)
   - Connect iPhone to Mac
   - Open QuickTime
   - File → New Movie Recording
   - Select iPhone as source

2. **Built-in Screen Recording**
   - Add to Control Center
   - Swipe down, tap record
   - Stop from status bar

### Windows + Android Emulator
1. **OBS Studio** (Free)
   - Download from obsproject.com
   - Record specific window
   - High quality output

2. **Windows Game Bar**
   - Press Win + G
   - Click record button
   - Focus on emulator window

## ✅ Quality Checklist

### For Screenshots:
- [ ] High resolution (1080p or higher)
- [ ] No personal information visible
- [ ] UI is clear and readable
- [ ] Shows key features
- [ ] Good lighting (not washed out)
- [ ] Clean status bar

### For Video:
- [ ] Smooth, not choppy
- [ ] Audio clear (if narrating)
- [ ] Shows all core features
- [ ] 60-90 seconds length
- [ ] Starts and ends cleanly
- [ ] No awkward pauses
- [ ] Demonstrates user flow

---

## 💡 Pro Tips

### Screenshots:
1. Use a clean wallpaper on device
2. Clear notifications before capturing
3. Full battery icon looks better
4. Take multiple shots, choose best
5. Crop if needed for focus

### Video:
1. Practice the flow before recording
2. Keep movements smooth
3. Don't rush - let animations play
4. Show features in logical order
5. Add background music (optional)
6. Keep file size under 50MB

### Presentation:
1. Start with most impressive feature
2. Show variety (different gradients)
3. Demonstrate user journey
4. End on a strong note
5. Keep it professional

## 📋 Pre-Recording Checklist

### Setup App:
- [ ] Clear all favorites
- [ ] Close any background apps

- [ ] Close unnecessary notifications

### Test Run:
- [ ] Practice the demo flow
- [ ] Time yourself (aim for 60-90s)
- [ ] Check all features work
- [ ] Prepare 4-5 quotes to favorite

### Recording Settings:
- [ ] Screen brightness at 75-100%
- [ ] Volume off (or background music)
- [ ] Portrait orientation
- [ ] High quality recording mode
